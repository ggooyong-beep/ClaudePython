# Use Case

| UC ID | 이름 | 행위자 | 주 흐름 | 관련 SWR |
|---|---|---|---|---|
| UC-01 | 운전자 잠금/해제 명령 | 운전자 | 운전자가 4개 경로 중 하나로 좌/우/전체 lock·unlock을 보낸다. SW는 입력을 검증하고 우선순위를 평가한 뒤 선택 측 출력을 갱신하고 이벤트를 기록한다. | SWR-001, 002, 004, 013, 022 |
| UC-02 | 이동 시작 자동 잠금 | 차량 | 유효 차속이 3.0 km/h 이상이 되면 SW가 좌·우를 `LOCK`으로 한다. | SWR-003 |
| UC-03 | 후측방 접근위험 해제 억제 | 차량, 운전자 | 접근위험이 TRUE인 측은 `LOCK`이 유지된다. 10초 이하 안에 같은 해제 명령을 다시 입력하면 override된다. | SWR-005, 006, 009 |
| UC-04 | 충돌 긴급 해제 | 차량 | `crash_status`가 `CONFIRMED`가 되면 좌·우를 `RELEASE`한다. `PENDING`은 출력을 바꾸지 않는다. | SWR-007, 008 |
| UC-05 | 비상 강제 해제 | 차량 | 화재, 과온, 성인 존재가 TRUE이면 좌·우를 `RELEASE`한다. | SWR-017 |
| UC-06 | ISOFIX 강제 잠금 | 차량 | ISOFIX가 연결된 측을 `LOCK`한다. | SWR-018 |
| UC-07 | 시동 OFF 초기화 | 차량 | `ignition_on`이 FALSE이면 좌·우를 `RELEASE`하고 `OFF` 상태가 된다. | SWR-020 |
| UC-08 | 입력 이상 처리 | 차량 | 형식·범위 오류는 거절하고, 200 ms 초과 미갱신은 `DEGRADED`, `sensor_fault`는 `FAULT`로 직전 출력을 유지한다. | SWR-013, 021 |
| UC-09 | 상태 확인 | 운전자, 시험자 | Web 화면과 상태조회 API가 출력, 상태, 이유코드, 입력 유효성을 보여 준다. | SWR-014, 015 |
| UC-10 | 결정 이력 조회 | 시험자 | 최근 100건의 결정 이벤트를 조회한다. 개인정보와 영상·음성은 저장하지 않는다. | SWR-010, 011, 012 |
| UC-11 | 재현 시험 | 시험자 | 같은 입력 순서를 고정 시계로 재생해 같은 결과를 확인한다. | SWR-016, 023 |
