# 기법·규격 참조

## 동치 클래스 (EP)
1. 파라미터별로 입력 도메인을 분할: 유효 클래스(요구사항이 정상 처리를 규정), 무효 클래스(범위 밖, 타입 오류, 신호 무효/타임아웃, NaN).
2. 상태/모드 파라미터는 모드별 클래스.
3. 유효 클래스는 조합 가능한 한 하나의 TC에서 함께 커버해도 되나, **무효 클래스는 TC당 1개**(결함 마스킹 방지) — PICT `~` 사용 시 동일 효과.
4. 클래스당 대표값은 경계가 아닌 내부값(경계는 BVA가 담당).

## 경계값 분석 (BVA)
- 닫힌 범위 [min,max]: min-1, min, min+1, max-1, max, max+1 (필요에 따라 min, min+1, max-1, max, 무효 2개로 축소 — 이유를 analysis에 기재).
- 시간/타이머: 임계-1 tick, 임계, 임계+1 tick (분해능 명시).
- 카운터/디바운스: N-1회, N회, N+1회.
- 히스테리시스: 상승/하강 양방향 임계.
- 부동소수점/ADC: 분해능(LSB)·허용오차 반영.
- 한 TB에 경계가 없으면(불리언 등) BVA 비적용 사유를 analysis에 `n/a` + 사유로 기록.

## 페어와이즈 (PICT)
- 적용 판단: 독립 입력 파라미터 ≥3, 값 조합이 결과에 영향. 단일 입력 요구사항에는 적용하지 않는다(억지 적용 금지).
- 모델 문법: https://github.com/microsoft/pict/blob/main/doc/pict.md
  - 주의: 숫자 값은 제약에서 따옴표 없이 비교(`[Speed]=0`), 문자열은 따옴표(`[Gear]="R"`). 모델 파일은 UTF-8(BOM 가능). 비ASCII 경로는 래퍼가 자동 처리.
  - 제약, 무효값 `~`, 가중치 `(n)`, 별칭 `a|b`, 하위모델 `{ A, B } @ 2`, 시드 `/e:seed.txt`.
- 출력의 `~` 접두 값은 무효 클래스 → 기대 결과는 오류 처리/무시/안전 상태 규정에 따라 작성.

## WoW 검증 (엣지)
엣지 후보 체크리스트: 전원 ON/OFF·브라운아웃 / 초기화 중 입력 / 모드 전환 경계 / 통신 타임아웃·CRC 오류·롤링카운터 오류 / 동시 이벤트·우선순위 / 반복·연속 입력 / 최대 부하 / 오버플로·언더플로·롤오버 / 센서 단선·단락·범위 이탈 / 복귀(recovery)·재시도 / 안전 상태 진입 후 재진입.
각 엣지 TC는 `techniques`에 `WoW 검증` 포함, 기대 결과는 요구사항(또는 안전 메커니즘 명세)에 근거.

## 쓰레기 TC 판별 기준 (생성 금지)
- 이미 커버된 클래스와 같은 결과 경로의 중복 입력
- 기대 결과가 "오류 없음/정상" 등 판정 불가
- 물리적/논리적으로 도달 불가능한 입력 조합
- 하나의 TB를 명목상 참조만 하고 실제로는 검증하지 않음
- 환경상 실행 불가(필요 장비·신호 접근 불가)

## A-SPICE 대응
| 요구 | 반영 |
|---|---|
| 테스트 명세 + TC 개발 | TC 시트(ID, 입력, 절차, 기대값, 기법) |
| TC 선정(회귀·우선순위 기준) | `priority`/ASIL 컬럼 |
| 양방향 추적성 | 추적성 매트릭스 + TC의 TB ID, 검증 스크립트 |
| 일관성 | 검증 스크립트의 고아/미커버 검사 |
| 결과 요약 | `요약` 시트 (실행 결과 컬럼은 공란으로 둠) |
(SYS.5=시스템 요구사항 대비, SWE.6=SW 요구사항 대비. 판(PAM 3.1/4.0)에 따라 BP 번호·명칭이 다르므로 인용 시 확인.)

## ISO 26262-6 대응
- 요구사항 기반 TC: 모든 TC가 SW 안전 요구사항/SW 요구사항에 추적.
- TC 도출: 요구사항 분석, 동치 클래스, 경계값, 오류 추정(= WoW 엣지).
- 통합/임베디드 테스트: 인터페이스 테스트, 결함 주입(안전 메커니즘 검증), 자원 사용 평가(비기능), 필요 시 Back-to-back.
- ASIL 컬럼을 두고 ASIL C/D는 BVA·결함 주입·3-way 조합(PICT `--order 3`)을 더 엄격히 검토.
- 구조적 커버리지는 단위/통합 수준 증거이며 본 스킬 범위 외(요구사항 커버리지가 대상). 필요 시 제안으로만 언급.
